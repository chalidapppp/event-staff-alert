# หน้าเว็บงานอีเวนต์ใกล้ฉัน (หางานสตาฟ / usher)

หน้าเว็บที่รวมงานที่จะจัดที่ **ไบเทค, ศูนย์ประชุมฯ สิริกิติ์, ราชมังคลา/หัวหมาก, บางกะปิ/รามคำแหง** เปิดบนมือถือได้ ไม่ต้องโหลดแอป
เอเจนซี่มักเปิดรับสตาฟล่วงหน้า 1–3 สัปดาห์ รู้ก่อนว่ามีงานอะไร = ไปค้นประกาศและทักได้ก่อนคนอื่น

- อัปเดตเองวันละ 3 รอบ (08:00, 13:00, 19:00) บน GitHub **ฟรี**
- **ไม่ต้องใช้ Claude** ไม่ต้องเปิดคอมทิ้งไว้ และไม่ต้องโหลดแอป
- กดเพิ่มไว้หน้าจอหลักมือถือ จะเปิดได้เหมือนแอป

## หน้าเว็บมีอะไร

- รายการงานแบ่งเป็น **กำลังจัดอยู่**, **ภายใน 10 วัน (ช่วงหาสตาฟ)** และ **ถัดไป**
- ปุ่มกรองตามโซน
- ป้าย **ใหม่** สำหรับงานที่เพิ่งประกาศใน 3 วันล่าสุด
- ป้าย **ชนวันที่ไม่ว่าง** สำหรับงานที่ตรงกับวันที่ตั้งไว้ใน `avoid_dates` (ตอนนี้ใส่ 21–22 พ.ย. วันก่อนสอบและวันสอบ AISA)
- ปุ่ม **หาสตาฟใน FB** ค้นโพสต์ `staff + ชื่องาน` ใน Facebook ให้ทันที

## วิธีติดตั้ง (ทำครั้งเดียว ประมาณ 10 นาที แนะนำให้ทำบนคอม)

### ขั้นที่ 1: สร้าง repository บน GitHub
1. สมัคร / ล็อกอิน [github.com](https://github.com)
2. กด **New repository** ตั้งชื่อ `event-staff-alert` เลือก **Public** แล้วกด **Create repository**
   - ต้องเป็น Public เพราะหน้าเว็บฟรี (GitHub Pages) ใช้ได้กับ Public เท่านั้น
   - คนอื่นที่เข้ามาดู repository จะเห็นรายการงานกับวันที่ใน `avoid_dates` แต่ไม่มีข้อมูลส่วนตัวอื่น
3. กด **uploading an existing file** แล้วลาก 4 ไฟล์นี้จากโฟลเดอร์ `D:\Claude\event-staff-alert` ใส่:
   - `watch_events.py`
   - `config.json`
   - `page_template.html`
   - `README.md`
   แล้วกด **Commit changes**
4. สร้างไฟล์ตั้งเวลา: กด **Add file → Create new file**
   - ช่องชื่อไฟล์พิมพ์: `.github/workflows/event-watch.yml`
   - เปิดไฟล์ `D:\Claude\event-staff-alert\.github\workflows\event-watch.yml` ด้วย Notepad ก๊อปทั้งหมดมาวาง
   - กด **Commit changes**

### ขั้นที่ 2: รันครั้งแรก
1. กดแท็บ **Actions** (ถ้ามีปุ่มให้เปิดใช้ ให้กดเปิด)
2. เลือก **event-watch** ทางซ้าย → กด **Run workflow** → **Run workflow**
3. รอประมาณ 1 นาทีจนขึ้นเครื่องหมายถูกสีเขียว ✅ จะมีโฟลเดอร์ `docs` เพิ่มขึ้นมาใน repository

### ขั้นที่ 3: เปิดหน้าเว็บ
1. กด **Settings → Pages**
2. ตรง **Source** เลือก **Deploy from a branch**
3. ตรง **Branch** เลือก `main` และโฟลเดอร์ `/docs` แล้วกด **Save**
4. รอ 1–2 นาที หน้าเว็บจะอยู่ที่
   `https://ชื่อผู้ใช้GitHub.github.io/event-staff-alert/`

### ขั้นที่ 4: เพิ่มไว้หน้าจอหลักมือถือ
เปิดลิงก์ข้างบนในมือถือ แล้ว
- **iPhone (Safari):** กดปุ่มแชร์ ⬆️ → **เพิ่มไปยังหน้าจอโฮม**
- **Android (Chrome):** กด ⋮ → **เพิ่มลงในหน้าจอหลัก**

เสร็จแล้วค่ะ จากนี้ระบบอัปเดตหน้าเว็บเองวันละ 3 รอบ

## ปรับแต่ง (แก้ไฟล์ `config.json` บน GitHub ได้เลย กดรูปดินสอ ✏️)

| ค่า | ความหมาย | ตอนนี้ |
|---|---|---|
| `avoid_dates` | วันที่ไม่ว่าง งานที่ตรงวันเหล่านี้จะมีป้ายเตือน | 21–22 พ.ย. 2026 |
| `look_ahead_days` | ดูงานล่วงหน้ากี่วัน | 60 |
| `remind_days_before` | งานที่เหลือไม่เกินกี่วันจะนับเป็น "ช่วงหาสตาฟ" | 10 |
| `zones` | โซนที่สนใจ: ชื่อ, พิกัด, รัศมี (กม.), คำค้นชื่อสถานที่ | 4 โซน |

อยากเพิ่มโซน เช่น อิมแพ็ค เมืองทอง ให้ก๊อปบล็อกโซนเดิมมาแก้ชื่อ พิกัด และคำค้น

## ถ้ามีปัญหา

- **หน้าเว็บไม่อัปเดต:** ดูแท็บ Actions ว่ารอบล่าสุดเป็น ✅ หรือ ❌ กดเข้าไปดูข้อผิดพลาดได้
- **Actions ขึ้น ❌ ตรงขั้น "Save what was already sent":** ไปที่ Settings → Actions → General → Workflow permissions เลือก **Read and write permissions** แล้วกด Save
- **GitHub ส่งอีเมลว่าจะหยุดรัน workflow:** กดลิงก์ในอีเมลเพื่อเปิดใช้ต่อ
- **บรรทัดล่างสุดของหน้าเว็บมี ✗ ที่แหล่งใด:** เว็บนั้นดึงไม่ได้รอบนั้น แหล่งอื่นยังทำงานตามปกติ
- **อยากหยุด:** แท็บ Actions → event-watch → ปุ่ม `...` → **Disable workflow**

## เสริม: แจ้งเตือนผ่าน Telegram (ไม่บังคับ)

ถ้าวันหลังอยากได้แจ้งเตือนเด้งเข้ามือถือ ให้สร้างบอทกับ @BotFather ใน Telegram แล้วใส่ `TELEGRAM_BOT_TOKEN` กับ `TELEGRAM_CHAT_ID`
ไว้ใน Settings → Secrets and variables → Actions ระบบจะเริ่มส่งข้อความให้เองโดยไม่ต้องแก้โค้ด
